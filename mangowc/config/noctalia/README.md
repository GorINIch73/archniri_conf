# Noctalia add-ons for the MangoWC trial

No plugin is required for ordinary static wallpapers: Noctalia owns the picker,
wallpaper selection, transitions, and dynamic palette.

Optional add-ons from Noctalia's Plugin Store:

- `0lucasmatheus/awwwall` — only if you want awww transitions or animated GIFs.
- `noctalia/mpvpaper` — optional video wallpaper picker. Keep it disabled until
  you want to try video wallpapers; configure its auto-pause option to pause
  when a window is fullscreen.

The Mango profile does not start `awww-daemon`. Awwwall manages it when enabled.
